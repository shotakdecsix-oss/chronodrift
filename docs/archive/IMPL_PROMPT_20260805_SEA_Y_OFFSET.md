# 実装指示: 海面が地形の下に隠れる — `seaYOffset()` を復活させる

作成: 2026-08-05 / 実機の数値実測で確定。**変更は1関数。**

`IMPL_PROMPT_20260805_COASTLINE_NO_MASK.md` の「5. 次に出るかもしれないこと」がそのまま出た。

---

## 1. 実測(水面のはずなのに陸に見える地点)

```
足元Y 22.85   SEA_Y 22.00   水面Y 22.15   elevBase -11   mask false
```

実標高換算(`Y / ELEV_SCALE + elevBase` = `Y/2 - 11`):

| | ゲーム高さ | 実標高 |
|---|---|---|
| 海面(描画) | 22.15 | **0.075m**(実標高0m + `WATER_VISUAL_MARGIN` 0.15) |
| 足元の地形 | 22.85 | **0.425m** |

**地形が海面より 0.7ゲーム単位(実測0.35m)高い。** だから海面が地形に隠れて陸に見える。

### 計算が完全に一致する

`landFloorM = seaLevelM(0) + LAND_FLOOR_MARGIN_M(0.5) = 0.5m`(part6.js)
→ ゲーム高さ `(0.5 - (-11)) × 2 = 23.0`
→ `farSurfaceY` は `FAR_Y(-0.15)` を含むので **22.85**

**実測の `足元Y 22.85` と一致。** 推測ではなく確定。

### 原因

地形側(`loadWideTerrain` / `loadNearTerrain`)は、**標高サンプルが `null` でない限り
必ず `Math.max(m, landFloorM)` で0.5m以上に底上げする**(江東区0m地帯対策の既存ロジック)。

海の上でも標高プロバイダが `0` を返した点は0.5mに持ち上げられ、
実標高0m固定の海面より高くなる。`null` を返した点だけ `oceanFloor` に落ちて海面が見える。
**プロバイダの応答が点ごとに違うので、海がまだらに陸として現れる。**

`mask false` なので、coastline を地形マスクから外した前回の修正は正しく効いている。
これはその副作用ではなく、**マスクが海面を守らなくなったことで露出した既存の性質**。

## 2. 修正(1関数)

```js
// js/legacy/part4.js — seaLevelY() の直後
// 【2026-08-05・実測で復活】地形側は landFloorM(海抜+0.5m)まで必ず底上げされる(part6.js)。
// 海面をその上に置かないと、標高データが返ってきた海上で地形に隠れて陸に見える
// (実測: 足元Y 22.85 / 海面Y 22.15)。
// Phase4 で「適合カットが海面を守る」前提のもと撤去したが、
// IMPL_PROMPT_20260805_COASTLINE_NO_MASK.md で coastline をマスクから外したため
// その前提は消えた。前提が変わったので戻す。
function seaYOffset() { return LAND_FLOOR_MARGIN_M * ELEV_SCALE + 0.3; } // = 0.5*2 + 0.3 = 1.3
```

`processCoastlineFill` の `buildFixedFlatAreaPoly` 呼び出し(2箇所)の `yOff` を
`WATER_VISUAL_MARGIN` から `seaYOffset()` に戻す。

### 効果(数値で検算済み)

海面 = `seaLevelY() + seaYOffset()` = `22.00 + 1.3` = **23.30**
地形の底上げ上限 = **22.85**
→ **0.45ゲーム単位(実測0.225m)上に来る。** 隠れなくなる。

## 4. 既知のトレードオフ(明示しておく)

海面が実標高 **+0.225m** に置かれるので、**実際に標高0.5m前後の海岸低地は
わずかに水没して見える**。これはマスク導入前から受け入れていた仕様。

根本的に消すには「海域では `landFloorM` の底上げを適用しない」という
地形側の変更が要るが、**それは別課題**。今回と混ぜないこと。
